# voyd

Small, free, open-source apps. No accounts, no ads, no tracking.

| | App | What it is | |
|---|---|---|---|
| <img src="https://voydapps.github.io/shrike/apple-touch-icon.png" width="48" alt=""> | **[Shrike](https://voydapps.github.io/shrike/)** | A fast image viewer for Mac. Press Space and the next photo is already there. Browse, rate, compare and make light edits. | [Download](https://github.com/voydapps/shrike/releases/latest) · [Code](https://github.com/voydapps/shrike) |
| <img src="https://voydapps.github.io/letterdock/apple-touch-icon.png" width="48" alt=""> | **[Letterdock](https://voydapps.github.io/letterdock/)** | An email app for Windows with as many accounts as you like. Your mail stays on your PC. | [Download](https://github.com/voydapps/letterdock/releases/latest) · [Code](https://github.com/voydapps/letterdock) |

Every app is MIT-licensed, and every release is built on GitHub from the public code.

Found a problem? Open an issue in the app's repository.
